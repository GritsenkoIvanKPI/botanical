# Botanical Extracts Pro — встановлення сайту та заявок у Telegram

Ця інструкція — для того, хто завантажує сайт на хостинг. Програмувати не
потрібно: усе робиться у файловому менеджері хостингу та в Telegram.
Час — приблизно 15 хвилин.

**Що вийде в результаті:** сайт працює на `botanicalextracts.pro`, а кожна
заявка з форми «Request a quote» одразу приходить повідомленням у Telegram.

---

## Що в архіві

```
public_html/              ← вміст цієї теки завантажити на хостинг
├── index.html            сайт
├── images/               фотографії
├── send-form.php         обробник форми: приймає заявку й пересилає в Telegram
├── config.example.php    зразок налаштувань (з нього робиться config.php)
├── .htaccess             правила сервера: захист налаштувань, HTTPS, кеш
├── robots.txt, sitemap.xml          для Google
└── favicon.ico, og-image.jpg, …     іконки та картинка для посилань
ІНСТРУКЦІЯ.md             цей файл (на хостинг не завантажувати)
```

Файл `.htaccess` починається з крапки, тому на компʼютері він може бути
прихований. На Mac у Finder натисніть `Cmd + Shift + .`, у Windows увімкніть
«Приховані елементи» у вкладці «Вигляд».

---

## Крок 1. Створити бота в Telegram

1. У Telegram знайдіть **@BotFather** і надішліть йому `/newbot`.
2. Вкажіть назву (наприклад, `Botanical Requests`) та username — він має
   закінчуватися на `bot` (наприклад, `botanical_requests_bot`).
3. BotFather надішле **токен** такого вигляду: `1234567890:AAH…`

**Токен — це пароль від бота.** Не пересилайте його в чатах і не публікуйте.

## Крок 2. Дізнатися, куди надсилати заявки (chat_id)

Заявки найзручніше приймати в групу: туди можна додати всіх, хто відповідає
клієнтам, і історія заявок буде спільною.

1. Створіть у Telegram групу та додайте в неї щойно створеного бота.
2. Напишіть у групу будь-яке повідомлення.
3. Відкрийте в браузері адресу, підставивши свій токен:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Знайдіть у тексті `"chat":{"id":-1001234567890` — це число і є **chat_id**.
   У групи воно відʼємне (з мінусом), мінус теж потрібен.

Якщо сторінка показує порожній `"result":[]` — напишіть у групу ще раз і
оновіть сторінку.

*Хочете отримувати заявки в особистий чат, а не в групу? Напишіть боту
`/start` зі свого акаунта і виконайте ті самі пункти 3–4: chat_id буде
додатним числом.*

## Крок 3. Завантажити сайт на хостинг

Приклад для Hostinger; на іншому хостингу кроки ті самі.

1. **hPanel → Файли → Файловий менеджер**, відкрийте теку `public_html`.
2. Якщо там є файли-заглушки (`default.php` тощо) — видаліть їх.
3. Завантажте **вміст** теки `public_html` з архіву (не саму теку, а те, що
   всередині), разом із текою `images` та файлом `.htaccess`.
4. Перевірте версію PHP: **hPanel → Додатково → Конфігурація PHP** — має бути
   **8.0 або новіша**.
5. Перевірте, що для домену увімкнено **SSL** (hPanel → Безпека → SSL). Сайт
   сам перенаправляє відвідувачів на `https://`.

## Крок 4. Створити config.php

1. У файловому менеджері, у теці `public_html`, скопіюйте файл
   `config.example.php` і назвіть копію **`config.php`**.
2. Відкрийте `config.php` і впишіть свої значення замість двох `PASTE_…`:

```php
<?php
return [
    'bot_token' => '1234567890:AAH…',     // токен із кроку 1
    'chat_id'   => '-1001234567890',      // число з кроку 2
    'notify_email' => '',                 // копія заявок на пошту; порожньо = вимкнено
    'rate_limit_per_hour' => 5,           // заявок з однієї адреси за годину
];
```

3. Збережіть файл.

`config.php` створюється **тільки на сервері**. Його немає в архіві й не може
бути у відкритому доступі: `.htaccess` забороняє відкривати його з браузера.

## Крок 5. Перевірити

**Швидка перевірка сервера.** Відкрийте в браузері:

```
https://botanicalextracts.pro/send-form.php?selftest=1
```

Має зʼявитися приблизно таке:

```json
{"ok":true,"php_ok":true,"config_present":true,"token_present":true,
 "chat_id":"-1001234567890","can_send":true}
```

| Що бачите | Що це означає |
|---|---|
| `"config_present":false` | `config.php` не створено або він не в `public_html` |
| `"token_present":false` | у `config.php` не вписано токен |
| `"can_send":false` | хостинг не дозволяє вихідні запити — зверніться в підтримку хостингу |
| `"php_ok":false` | стара версія PHP — увімкніть 8.0+ |

Сам токен на цій сторінці не показується — лише те, чи він є.

**Справжня перевірка.** Відкрийте сайт, заповніть форму «Request a quote» і
натисніть «Send my request». На сайті зʼявиться «Request sent.», а в групу
протягом кількох секунд прийде повідомлення.

## Як виглядає заявка в Telegram

```
🌿 New request · Botanical Extracts Pro

Name: Claire Dubois
Company: Maison Dubois
Email: claire@maisondubois.fr
Phone / WhatsApp: +33 6 11 22 33 44

Interested in: Natural essential oils

Page: /
09.10.2026 06:38 UTC
```

- Email і телефон копіюються одним дотиком.
- **Interested in** показує, з якої кнопки прийшов клієнт: назву категорії
  («Natural essential oils», «CO₂ extracts»), «Certificates & documentation»,
  «Wholesale quotation» тощо. Якщо клієнт відкрив форму напряму —
  «General enquiry».
- Час вказано за UTC (Франція — UTC+1 взимку, UTC+2 влітку).

## Що бачить відвідувач сайту

| Ситуація | Що відбувається |
|---|---|
| Заявку надіслано | Замість форми зʼявляється «Request sent.» |
| Не заповнено обовʼязкові поля | Форма просить їх заповнити й не надсилається |
| Понад 5 заявок за годину з однієї адреси | Прохання спробувати за годину або написати у WhatsApp |
| Telegram тимчасово недоступний | Прохання спробувати ще раз або написати у WhatsApp |
| `config.php` ще не налаштовано | Відкривається поштова програма відвідувача з готовим листом — заявка не губиться |

## Захист

- **Токен не потрапляє в браузер.** Сторінка звертається лише до
  `send-form.php`; токен лежить у `config.php` на сервері.
- **Захист від спам-ботів.** У формі є приховане поле-пастка: людина його не
  бачить, а бот заповнює — така «заявка» мовчки відкидається.
- **Обмеження частоти** — не більше 5 заявок на годину з однієї адреси
  (змінюється в `config.php`).
- **Перевірка даних на сервері**: імʼя та компанія, коректний email, згода на
  обробку даних. Будь-який код у полях перетворюється на звичайний текст.

## Якщо заявки не приходять

1. Відкрийте `…/send-form.php?selftest=1` і звіртеся з таблицею у кроці 5.
2. Переконайтеся, що бот **доданий у групу** і `chat_id` саме цієї групи.
3. Якщо групу перетворили на «супергрупу», її `chat_id` змінюється —
   повторіть крок 2.
4. Подивіться файл `error_log` у `public_html` (зʼявляється після першої
   помилки): скрипт записує туди причину.

## Якщо токен потрапив до сторонніх

У @BotFather: `/revoke` → оберіть бота → отримайте новий токен → впишіть його
в `config.php`. Старий токен одразу перестане працювати.

## Корисно знати

- **Оновлення сайту.** Щоб оновити сайт, замініть `index.html` та теку
  `images` новими. `config.php` чіпати не потрібно — налаштування збережуться.
- **Google.** Після запуску додайте сайт у Google Search Console і надішліть
  карту сайту `https://botanicalextracts.pro/sitemap.xml`.
- **Тимчасова адреса.** Попередній перегляд сайту на `botanical-liart.vercel.app`
  заявки в Telegram не надсилає (там немає PHP) — форма відкриває поштову
  програму. Після запуску на своєму домені попередній перегляд варто вимкнути,
  щоб Google не бачив дві копії сайту.
